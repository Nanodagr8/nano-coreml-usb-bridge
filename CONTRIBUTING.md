# Contributing to NANO CoreML USB Bridge

We welcome reproducible platform testing, small code improvements, security findings, packaging work, and rigorous Neural Engine hardware measurements.

For each pull request, specify operating systems, physical hardware or simulator, tool versions, commands executed, and actual observed output. Clearly distinguish static tests, simulator results, physical-device results, and independent ANE operator placement measurements.

Never publish private keys, Apple signing identities, certificate passwords, live bearer tokens, private pairing records, user-specific UDIDs, unredacted diagnostics or copyrighted model weights.

Report security concerns without attack secrets in public issues; contact maintainers to arrange private communication when needed. Contributions must be compatible with this project's MIT license; existing dependencies keep their own licenses.
